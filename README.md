# SpaceFix

SpaceFix исправляет ошибочную раскладку и словарные опечатки после пробела. Приложение работает в фоне в Windows и поддерживает английскую, русскую и казахскую раскладки.

## Как пользоваться

Скачай и запусти `SpaceFix.exe` из [раздела Releases](https://github.com/promaladoi/SpaceFix/releases). Двойной щелчок по значку SpaceFix рядом с часами откроет панель с полем проверки.

- Набери `ghbdtn` в английской раскладке и нажми пробел. SpaceFix исправит ввод на `привет`.
- Набери `копше` в русской раскладке и нажми пробел. SpaceFix исправит слово на `көпше` и переключит раскладку на казахскую, если она подключена в Windows.
- Нажми `F10`, чтобы отменить последнюю замену.
- Открой «Личный словарь» в панели или в меню рядом с часами, чтобы добавить свои замены и исключения.

Словари встроены в приложение, поэтому исправления работают без интернета. Неоднозначные варианты казахских слов остаются как набраны. Правила личного словаря имеют приоритет и сохраняются на компьютере.

## Сборка

В Windows запусти `build.ps1` из папки проекта. Скрипт использует компилятор .NET Framework и встроит готовые словари из `data` в `SpaceFix.exe`.

Источники и лицензии словарей перечислены в [data/credits.txt](data/credits.txt). Там же указан [исходный список казахской лексики A1–C1](https://huggingface.co/datasets/Gulnur7/kazakh-lexical-complexity-classes/tree/85ce668badb9ab7d2477056d4cf31772e7698dd6), который нужен для повторной генерации вариантов. Для обычной сборки достаточно уже подготовленных файлов в `data`.
